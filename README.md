# Professional Self-Assessment

Completing my coursework throughout the Computer Science program and developing this ePortfolio has helped me recognize, refine, and communicate the strengths I bring to the field. Across the program, I have grown from completing isolated programming assignments into thinking like a software professional who can analyze requirements, design maintainable solutions, manipulate data effectively, improve existing code, and explain technical decisions to different audiences.

The program strengthened my interest in software development that is reliable, understandable, and useful to real users. I value solutions that are not only functional, but also organized, efficient, secure, and maintainable. Developing the ePortfolio reinforced those values because it required me to revisit prior work, evaluate it critically, and enhance it beyond its original course requirements. Such as making a database more dynamic by adding additional data filtering and graphs to present the data.

### <ins>Collaboration in a Team Environment</ins>
Collaboration was an important part of my development because it taught me that successful software projects depend on more than individual technical ability. In a team it is imperative to coordinate responsibilities, listen to different approaches, and contribute work that could be understood and built upon by others. Even when working independently, I learned to write code and explanations as if another developer would later maintain or extend my work. That mindset is essential in a professional setting because software is rarely owned by one person forever.
I have learned that effective communication means adapting the level of detail to the audience. A technical reviewer may need to understand implementation decisions, data flow, or algorithmic tradeoffs, while a nontechnical stakeholder may need to understand how a change improves usability, reliability, security, or business value.

<u>Data Structures and Algorithms</u>
Data structures and algorithms became one of the clearest areas where I developed confidence. Through my coursework in this category, I learned how the organization of data directly affects the performance, readability, and scalability of a program. As shown in the ABCU program, I practiced creating data structures that fit the problem and searching/ presenting stored data according to user input. In the case of my program, I developed a data tree for hierarchical or connected data and used a Binary Tree Search for sorting through it.

<u>Software Engineering and Database Development</u>
In the Software Design Category I developed a program that rendered a 3D scene based on a picture I say once of a playground. While developing this program I gained a greater understanding of the importance of designing applications with structure and purpose. I strengthened my ability to break problems into smaller components, separate responsibilities, improve naming and organization, and modulization of software code. 
The Database program I am showcasing in my portfolio expanded that foundation by showing me how applications depend on accurate, well-structured, and secure data. I gained experience with storing, retrieving, updating, and organizing information while considering data integrity and the relationship between the application layer and the data layer. This database program demonstrates my understanding of CRUD (Create, Read, Update, Delete) operations and how design decisions on the presentation of the database, i.e. graphs and maps, affect the analysis of the data. Whether working with structured records, queries, or persistent application data, I learned that strong database design supports better software behavior and better decision-making for users.

<u>Security Awareness</u>
Security became an important professional value throughout the program. I learned that secure software development is not limited to a final review or a separate checklist; it should be considered throughout requirements, design, implementation, testing, and maintenance. My work reinforces the importance of validating input, protecting sensitive data, limiting unnecessary access, handling errors carefully, and avoiding assumptions about how users or systems will behave. These practices strengthened my ability to think defensively and build software that is more trustworthy and resilient.

<u>How the Portfolio Artifacts Fit Together</u>
The technical artifacts that follow this self-assessment fit together as a cohesive demonstration of my computer science abilities. Collectively, they show that I can evaluate existing work, identify meaningful opportunities for improvement, and apply enhancements across multiple areas of computing. One artifact emphasizes software design and engineering by showing how structure, modularity, readability, and maintainability can improve an application. Another demonstrates data structures and algorithms by showing how data can be organized, processed, searched, or manipulated more effectively. A database-focused artifact demonstrates my ability to manage persistent information and present data in a meaningful way.

Together, these artifacts present more than a collection of assignments; they demonstrate growth, intentional improvement, and professional readiness. They show my ability to work across the software development lifecycle, communicate technical decisions, use data structures and databases effectively, apply secure development practices, and improve code quality over time. Completing this ePortfolio has helped me better understand the kind of computer science professional I aim to become: someone who builds thoughtful, reliable, secure, and maintainable software while continuing to learn and adapt.
